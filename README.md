# SQL Joins Analysis

## Project Overview
This project demonstrates the use of SQL Joins to combine data from multiple tables and extract meaningful information using SQL Server.

## Tools Used
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)

## Project Contents
- **Joins_Analysis.sql** – SQL queries
- **Questions File** – Assignment questions
- **Dataset File** – Data used for analysis

## Key Learnings
- Understanding different types of SQL Joins
- Combining data from multiple tables
- Writing SQL queries to solve data-related questions

## Objective
To strengthen SQL skills and understand how joins are used in data analysis.
